# Gavone per iPhone

Questi file sono il programma, senza nessun dato tuo. Vanno messi online una volta sola con GitHub Pages; da lì Gavone si installa sull'iPhone e catalogo e foto restano solo nel telefono.

1. github.com in Safari → **+** → **New repository** → nome `gavone`, **Public**, spunta **Add a README file** → **Create repository**.
2. **Add file → Upload files** → seleziona tutti i file di questa cartella → **Commit changes**.
3. **Settings → Pages** → Source **Deploy from a branch**, Branch **main** e **/ (root)** → **Save**.
4. Dopo 1-2 minuti apri `https://TUONOME.github.io/gavone/` in Safari → **Condividi → Aggiungi alla schermata Home**.
5. Apri Gavone **dall'icona** → **Ho già un backup: importalo** → scegli `gavone-backup-iniziale.json`.

Per aggiornare l'app in futuro basta ricaricare i file nuovi nello stesso repository: i dati nel telefono non si toccano.
